# 🛍️ Skylark Clothing - E-Commerce Web Application

Welcome to **Skylark**, a modern and trendsetting e-commerce web platform designed to elevate your style. Browse through our latest collections, featuring apparel for men, women, and various accessories.

- **Live Demo:** [https://sky-nine-puce.vercel.app/](https://sky-nine-puce.vercel.app/)

---

## 🌟 Features

- **Trendsetting Collections:** Easily browse through Men's, Women's, and Accessories categories.
- **Unified Product Management:** Streamlined product entry and collection management.
- **Featured Products:** Showcase top-selling clothing items with clean pricing (LKR) and product details.
- **Customer Benefits:** 
  - 🚚 Islandwide Delivery
  - 🔒 Secure Payments
  - 🔄 Easy 7-Day Returns
- **Responsive Design:** Optimized for seamless shopping experiences across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Modern CSS (Flexbox, Grid)
- **Deployment:** Vercel
